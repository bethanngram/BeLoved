# BeLoved

BeLoved is an adaptive, intelligent Christian formation ecosystem rooted in John 17:21: **“That they may all be one.”**

## Architecture

- Next.js + TypeScript application
- Supabase authentication and PostgreSQL member database
- Adaptive member journey engine
- Specialist AI-agent orchestration
- Content and Scripture intelligence
- Community, groups, events and service
- Member 360° administration
- Privacy-aware personal context and reflections
- Analytics and operational intelligence

## Connected Supabase

The BeLoved Supabase project already contains a substantial domain model including profiles, member belonging, life, people, formation, growth, profession, money, world, trust, network profiles, churches, church memberships, community needs, capacity, service opportunities, discipleship networks, world intelligence, resource flows, content, Scripture passages, journey moments, formation encounters and daily actions.

The application should use that existing model rather than replacing it.

## AI agents

The production orchestration layer should include Journey, Scripture & Christian Wisdom, Reflection, Formation, Stewardship, Love, Community, Discernment, Unity, Content and Administrative Intelligence agents.

Agents support the member; they do not claim divine authority or replace clergy, Scripture, conscience, professional expertise or human community.

## Integrations

Supabase is the system of record. GitHub is the source-control and CI/CD home. Optional integrations can include Notion for editorial/knowledge operations, Slack for internal operations, Figma for design-system work, and future media/storage providers for approved image/video/audio assets.

Never place secrets in source control. Use environment variables and server-side secrets for AI/provider credentials.
